## 🧠 MODEL ARCHITECTURE

### Generator Network:
- **Input**: 100-dimensional latent noise vector
- **Architecture**: 6 transposed convolution layers
- **Output**: 128×128 grayscale MRI image
- **Activation**: ReLU (hidden layers), Tanh (output layer)
- **Normalization**: Batch normalization after each layer
- **Parameters**: ~51.2 million trainable parameters

### Discriminator Network:
- **Input**: 128×128 grayscale MRI image
- **Architecture**: 6 convolution layers with strided convolutions
- **Output**: Binary classification (real/fake probability)
- **Activation**: LeakyReLU (0.2), Sigmoid (output)
- **Normalization**: Batch normalization in deeper layers
- **Parameters**: ~11.2 million trainable parameters

### Total Parameters: ~62.4 million trainable parameters

## 📊 TRAINING CONFIGURATION

### Hyperparameters:
- **Image Size**: 128×128 pixels
- **Batch Size**: 32 images
- **Learning Rate**: 0.0002 (Adam optimizer)
- **Beta1**: 0.5 (Adam optimizer)
- **Epochs**: 200 (with checkpoint resumption from epoch 120)
- **Latent Dimension**: 100
- **Loss Function**: Binary Cross-Entropy Loss (BCELoss)

### Training Features:
- **Label Smoothing**: One-sided label smoothing (0.85-1.0 for real, 0.0-0.15 for fake)
- **Label Flipping**: 10% probability of label flipping for discriminator regularization
- **GPU Optimization**: RTX 5070 optimizations with cuDNN benchmarking
- **Checkpointing**: Model saved every 10 epochs

## 🔧 EVALUATION SYSTEM

### Metrics Computed:
1. **FID (Fréchet Inception Distance)**:
   - Measures distribution similarity between real and generated images
   - Uses Inception network features (768-dimensional)
   - Lower is better (target < 50)

2. **SSIM (Structural Similarity Index)**:
   - Measures structural similarity between image pairs
   - Uses best-matching real images for each fake image
   - Higher is better (target > 0.70)

3. **PSNR (Peak Signal-to-Noise Ratio)**:
   - Measures reconstruction quality
   - Computed on best-matching image pairs
   - Higher is better (target > 25 dB)

### Evaluation Process:
- **Real Images**: 500 samples flattened from hierarchical structure
- **Generated Images**: 500-1000 synthetic samples
- **Best Matching**: MAE-based matching for SSIM/PSNR computation
- **Batch Processing**: Efficient batch generation and evaluation
